# Charlie MJ Language v5.0.0 — Final Complete Additive Update

This release intentionally keeps the extension version at **5.0.0**. It is an additive update to the previous v5.0.0 package.

## Preserved
- Existing transcript engine remains the primary/default engine.
- Existing settings/storage keys remain in place.
- Existing YouTube learning toolbar and Charlie MJ+ action remain integrated.
- Existing Favorites/Channels/Playlists/Learning Groups systems remain namespaced separately.

## Completed additions/fixes
- Category cards: View, Open, Edit, Remove, resource counts and category detail view.
- Category detail view lists channels and playlists belonging to the category.
- Extension Intelligence settings and JSON category knowledge base integration.
- Existing-category-first category suggestions; new-category suggestions require confirmation.
- YouTube Suggestions tab with CHANNEL/PLAYLIST separation and View/Open/Save/Ignore actions.
- Services settings for additive transcript/AI services.
- Additional Learning window controls: resize, minimize, maximize, pin, close, remembered state and configurable behavior.
- Data Sync settings for local directory permission, GitHub repository health check, compare, pull and backup preparation.
- Split database structure by resource type/category plus lightweight indexes.
- Performance settings with lightweight startup, on-demand service lifecycle, sleep timeout, lazy loading, cache and background-task controls.
- Scheduled GitHub pull is alarm-driven rather than continuously polling.
- legacy optional transcript comparison (removed in maintenance build) HTTP 403 fix: removed background player-session recreation and made the active YouTube page/session the authoritative caption source; transcript endpoint/network-observed responses remain available as fallbacks.
- Local AI activation/test path retained so a disabled service can be explicitly enabled/tested from the Additional Learning window.
- CSP audit confirms no inline HTML event handlers in source HTML files.

## Important platform behavior
Chrome extensions cannot write to arbitrary PC paths without explicit user permission. Data Sync therefore uses the browser's directory picker/File System Access permission for local database access. GitHub synchronization uses the GitHub Contents API.
