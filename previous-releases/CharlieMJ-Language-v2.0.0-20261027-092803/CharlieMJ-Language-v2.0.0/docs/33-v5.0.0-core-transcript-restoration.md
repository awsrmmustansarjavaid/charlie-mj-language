# v5.0.0 — Core Transcript Restoration

The original Charlie MJ YouTube transcript engine from the supplied previous source package is restored as the authoritative core.

Non-negotiable behavior preserved:
- Fast complete transcript fetching remains the primary transcript path.
- Transcript is independent of the visible YouTube CC switch when YouTube exposes caption tracks.
- The complete timestamped transcript remains scrollable to the end.
- Transcript rows remain clickable and seek the YouTube video timeline.
- Existing transcript synchronization, learning actions, subtitles, vocabulary, notes, bookmarks, Watch Later, exports, and transcript window behavior remain owned by the original engine.

The added services remain additive. legacy optional transcript comparison (removed in maintenance build) is not allowed to replace or become a dependency of the original transcript path. Additional services are loaded only when their UI/actions are used.
