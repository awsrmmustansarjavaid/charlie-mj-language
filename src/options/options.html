Translation provider

Translation Priority Order

Choose the exact fallback order. YouTube Captions — Native + Auto-Translation is one provider group and is Priority 1 by default. If Native captions exist in your target language they are used; otherwise YouTube Auto-Translation is requested from the original caption track. Each provider can appear only once.

YouTube Captions group: Native target captions are preferred; otherwise YouTube Auto-Translation uses the original/source caption track. The remaining priorities are used as fallbacks in the exact order selected above. YouTube processing is behind the scenes and does not click or change YouTube CC controls. Online providers are optional. API keys are stored locally in Chrome storage. Argos is not bundled; connect a locally installed Argos service when you choose offline translation.

Translation routing & privacy

Dictionary

Dictionary data is shown inside saved vocabulary cards. Wiktionary is the primary open dictionary source; DictionaryAPI.dev is used only as a lightweight fallback for supported languages.

Wiktionary/Kaikki is the runtime universal foundation. The architecture supports specialized open WordNet, Arabic WordNet, FarsNet and Turkish adapters. Reference websites are links only; the extension does not scrape them.

Transcript Windows Scroll

📜 Scroll & timeline sync (Transcript, Dual Transcript, YT Transcript Pro)

One set of scroll rules for all three transcript tabs. While the video plays, the list follows the current subtitle. While the video is paused, the list stays still. If you seek on the YouTube timeline (paused or playing) or click a line, the list jumps to that moment. Manual scrolling always works.

Press Save Settings to apply. Open YouTube tabs pick the new values up immediately.
