About & User Guide

Lightweight, local-first YouTube language learning. This page explains how the extension works and what to do when something needs attention.

Getting Started

Open a YouTube video, use the Charlie MJ toolbar, and choose Transcript, Dual Transcript, Word Learning, Sentence Learning, Focus Mode, or the other tools already available in your extension.

Dual Transcript — Original + Translation

Dual Transcript uses YouTube's own caption-track information. It displays the original transcript together with the selected YouTube translation when that translation is available. The extension does not replace your existing transcript engine.

If YouTube temporarily rejects a caption request, the translated column may be unavailable until YouTube accepts the request again.

Reset YouTube Network / Caption Connection

  1. Open the extension popup.
  2. Click ↻ Reset YouTube Network .
  3. The extension cancels its pending caption request, clears only the temporary Dual Transcript cache/request state, waits briefly, and performs one controlled retry.
  4. After the retry, it becomes inactive again; it does not continuously retry.

Important: HTTP 429 is returned by YouTube's /api/timedtext server endpoint. The extension cannot remove a server-side rate limit. Reset only cleans the extension's local request state and gives YouTube one fresh attempt.

Lightweight Sleep Mode

Use 💤 Lightweight Sleep from the popup when you are not using Charlie MJ. It pauses optional Charlie MJ page activity, stops Dual Transcript activity, clears its temporary in-memory translation state, and prevents scheduled background refresh work while sleep is enabled.

It does not delete your library, settings, vocabulary, transcripts, bookmarks, favorites, or other saved data.

Translation Providers

Charlie MJ keeps its existing provider system. Dual YouTube is an additional provider and does not replace YouTube Captions, Google, Microsoft, DeepL, MyMemory, LibreTranslate, Argos, or other configured providers.

Word Learning & Sentence Learning

When a successful sentence translation already exists, Charlie MJ can use that sentence context to resolve a word translation when the alignment is sufficiently safe. Otherwise the normal provider priority chain can continue.

Cache Management

Dual Transcript has its own temporary cache. The Network Reset button clears that Dual Transcript cache so the next request starts clean. Other extension data is not deleted by Network Reset.

Troubleshooting HTTP 429

  1. Check F12 → Network on the YouTube page.
  2. Filter for timedtext .
  3. Open the request and check the status code.
  4. If YouTube's www.youtube.com/api/timedtext request shows 429 Too Many Requests , YouTube is rejecting that caption request.
  5. Try the extension's Network Reset once. Do not repeatedly press it.
  6. If 429 continues, wait and test the same video in a fresh browser profile/Incognito session.

Settings & Library

Your existing Settings, My Learning Library, Collections, Favorites, Data Sync, transcript tools, vocabulary, sentence learning, bookmarks, notes, captures, and other systems remain separate from the two lightweight controls described here.

Privacy & Local-First Design

Learning records are stored locally by the extension unless an existing feature/provider explicitly uses an external service. Network Reset does not upload or delete your learning library.

FAQ

Does Network Reset remove YouTube's 429?

No. It cannot control YouTube's server-side rate limiter. It only resets the extension's local request state and performs one controlled retry.

Will Lightweight Sleep delete anything?

No. It only pauses optional activity.

Does Dual Transcript still show both columns?

Yes. When YouTube provides the requested original and translated caption tracks, Dual Transcript continues to show both.
