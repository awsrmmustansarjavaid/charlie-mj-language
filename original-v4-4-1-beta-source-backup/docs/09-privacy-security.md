# Privacy and Permissions

## Storage

Vocabulary, bookmarks, Watch Later entries and settings are stored in Chrome local storage.

## Network requests

Translation text may be sent to the configured translation provider. The user can configure a LibreTranslate server or disable automatic translation.

## Permissions

- `storage`: local learning data
- `downloads`: export learning files
- `contextMenus`: right-click learning actions
- `activeTab` / `scripting`: page integration
- `commands`: keyboard shortcuts
- `tabs`: active YouTube tab coordination
- YouTube host permission: video-page integration
- translation provider host permission: translation requests

## Privacy principle

Charlie MJ Language should not require an account for core learning. Users should be able to export their data and understand which external service receives translation text.
