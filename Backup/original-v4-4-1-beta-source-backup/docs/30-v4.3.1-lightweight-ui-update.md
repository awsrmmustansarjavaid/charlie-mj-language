# Charlie MJ Language v4.3.1 — Lightweight UI Update

## Base

v4.3.1 is based directly on the stable v4.3.0 extension build.

## Removed

- New YouTube Capture Engine layer and related capture-engine settings.
- Health Check and health-diagnostics UI.
- AI assistant / AI processing.
- Learning Report and Caption Diagnostics toolbar actions.

## Added / improved

- Drag subtitles anywhere in the browser window.
- Persist subtitle position locally.
- Reset subtitle position from Settings.
- Original and translation subtitle colors.
- Existing subtitle size, bold, underline and italic controls remain.
- Drag the Transcript window by its header.
- Resize the Transcript window from its resize corner.
- Minimum/maximum Transcript window width and height.
- Persist Transcript window size and position.
- Pin/unpin Transcript window on top.
- Reset Transcript window.
- Toolbar scale and width controls.
- Reduced continuous CPU work by replacing the 60fps subtitle polling loop with a lightweight scheduled loop and slowing the Watch Later menu probe.

## Stability goal

The YouTube caption/transcript architecture from v4.3.0 is intentionally retained instead of introducing the newer capture engine. Translation, dictionary, vocabulary, notes, bookmarks and exports remain available.
