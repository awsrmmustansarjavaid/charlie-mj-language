# UI/UX and Frontend Design

## Visual identity

The Charlie MJ identity combines a world globe, language symbols and the Charlie MJ name. The supplied icon is designed around global communication rather than a generic dictionary symbol.

## YouTube layer

The YouTube experience uses a dark midnight glass-style learning bar with compact controls:

`Transcript · Save · Bookmark · Capture · Focus · Watch Later · More`

The design deliberately keeps the most common actions visible and moves advanced actions into the three-dot menu.

## Subtitle design

Original text is displayed above translated text. Individual words receive POS-aware styling and optional CEFR labels. The learner can turn POS colors, bold formatting and levels on/off from settings.

## Focus Mode

Focus Mode does not destroy the underlying YouTube page. It reduces the visual prominence of discovery/recommendation areas and leaves the learner's video and learning controls dominant. This makes the system safer and more reversible than aggressively removing YouTube DOM nodes.

## Library dashboard

The dashboard uses cards, search, thumbnails, tags and separate views for Watch Later, Vocabulary and Bookmarks.

## Responsive design

The popup, dashboard and YouTube toolbar adapt to smaller screens. Desktop is the primary target because Chrome desktop provides the richest extension APIs and YouTube layout.
