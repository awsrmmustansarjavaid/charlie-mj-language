# Testing / Acceptance Checklist

## Basic fetch

- [ ] Open a normal YouTube video with manually authored captions.
- [ ] Open a video with auto-generated captions.
- [ ] Confirm the complete cue count is larger than only the currently visible subtitle.
- [ ] Change the target language and refresh.
- [ ] Confirm YouTube-native translation is used when that language is supported.

## Playback synchronization

- [ ] Play from the beginning.
- [ ] Pause and resume.
- [ ] Seek forward.
- [ ] Seek backward.
- [ ] Jump repeatedly through the timeline.
- [ ] Confirm original and translated lines change together.

## Navigation

- [ ] Navigate from video A to video B without reloading the YouTube tab.
- [ ] Open a YouTube Shorts URL.
- [ ] Return to video A and confirm cache reuse.

## UI

- [ ] Open DT transcript panel.
- [ ] Search transcript.
- [ ] Click a transcript sentence and verify video seeking.
- [ ] Change font size and opacity.
- [ ] Toggle the extension off/on.

## Failure cases

- [ ] Video has no captions.
- [ ] Video has captions but requested translation language is unavailable.
- [ ] YouTube returns an empty/HTML caption response.
- [ ] Network temporarily fails.
- [ ] YouTube changes its internal caption request path.

## Performance

- [ ] Verify no continuous network polling is generated by the extension.
- [ ] Verify the complete track is fetched once per source/target pair when uncached.
- [ ] Verify repeated viewing uses the local cache.
- [ ] Verify CPU usage remains reasonable on a long video.


### Dual-track validation

1. Open a YouTube video with captions.
2. Set a target language different from the source language.
3. Reload the video.
4. Wait for `Dual ready` in the panel.
5. Confirm the overlay shows original and YouTube-translated text.
6. Open the complete transcript panel using `DT`; confirm both columns are present and clicking a sentence seeks the video.
7. If YouTube has no translation track for the requested language, the panel must show the original transcript and an explicit translation-unavailable message.
