# Dual Transcript v1.0.0 Stable Beta — Final Additive Update

This release is additive to Charlie MJ Language. The existing v5.0.0 systems remain the base and are not replaced.

## Added in this update
- Dual Transcript remains available as an additional toolbar button and transcript-window tab.
- Dual Transcript view is protected from the existing transcript renderer overwriting its body.
- Original and translated subtitle colors are configurable in the dedicated Dual Transcript settings tab.
- A speaker icon follows the currently active Dual Transcript sentence and can seek/play that sentence. Speaker visibility, color, and size are configurable in the Dual Transcript settings tab.
- Minimized Transcript windows gain a hover-reveal restore/maximize affordance without changing the existing window minimize/maximize implementation.
- Notes Library receives an additional Add Note action. Existing Notes storage remains compatible; new standalone notes use the `__library__` namespace.
- GitHub repository URL now defaults to `https://github.com/awsrmmustansarjavaid/charlie-mj-language` while remaining editable.

## Preservation rule
No existing core transcript, toolbar, library, bookmark, Watch Later, settings, or learning implementation is intentionally replaced by these additions.
