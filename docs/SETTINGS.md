## Dual Transcript
The dedicated Dual Transcript settings can include:
- Target language
- Original subtitle color
- Translated subtitle color
- Speaker indicator enable/disable
- Speaker icon color
- Speaker icon size
- Synchronization behavior
- Cache/fetch behavior where supported
