# Dual Transcript User Guide

1. Open a YouTube video.
2. Start playback briefly if necessary.
3. Click **Dual Transcript** in the Charlie MJ Language toolbar, or open the Transcript window and select **Dual Transcript**.
4. Open **Settings → Dual Transcript**.
5. Select the target language.
6. Choose the original and translated subtitle colors.
7. Enable/configure the speaker indicator if desired.
8. Play the video and let the current sentence follow the timeline.
9. Use search to find words or phrases.
10. Save supported words or sentences into the existing learning library.

### If translation is unavailable
Check that the video has captions, confirm the target language is supported by YouTube, refresh Dual Transcript, or try another target language.

The original transcript remains independent.
