# Development Preservation Rules

This is a strict project rule.

1. **Add, don't remove.**
2. Existing working features are untouchable unless explicitly requested.
3. Do not replace the original transcript engine.
4. Do not remove existing settings.
5. Do not silently erase user data.
6. Optional services must fail independently.
7. Do not create a second YouTube player.
8. Avoid unnecessary continuous polling/network work.
9. Test existing functionality after every new integration.
10. Keep changes limited to the requested new feature.

A new feature is not considered successful if it breaks an existing working feature.
