# Roadmap

## Release 1 foundation

- Manifest V3.
- YouTube learning toolbar.
- Focus Mode.
- Caption transcript capture.
- Bookmarking.
- Timeline capture records.
- Vocabulary capture.
- Watch Later.
- Local storage.
- JSON/TXT export.
- Options page.

## Release 2 language intelligence

- Real translation provider adapter layer.
- Word-level aligned translation.
- Dictionary provider adapters.
- CEFR/frequency dictionaries.
- POS tagging.
- Lemma/morphology providers.
- Complete bilingual transcript export.

## Release 3 study system

- SRS engine.
- AnkiConnect.
- Flashcards.
- Learning sessions.
- Goals and statistics.
- Video learning reports.
- Smart vocabulary queue.

## Release 4 advanced media

- Audio extraction where browser permissions/platform rules allow.
- Screenshot assets.
- Shadowing and speech recognition.
- AI tutor.
- Local translation/NLP models.
- EPUB/web article learning.

## Release 5 desktop/mobile

- Tauri desktop application.
- Windows filesystem integration.
- Local MP4/MKV/SRT/VTT workflows.
- Mobile companion.
