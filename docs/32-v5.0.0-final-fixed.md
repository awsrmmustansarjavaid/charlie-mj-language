# Charlie MJ Language v5.0.0 — Final Additive Fix Pass

This pass keeps version 5.0.0 and adds/fixes the requested functionality without replacing the legacy transcript engine or existing settings/storage model.

## UI
- Charlie MJ+ is integrated into the existing YouTube toolbar instead of using an independent floating launcher.
- Additional Learning uses a dedicated window with drag, resize, minimize, maximize, pin and close controls.
- Additional window size/position can be remembered.
- YouTube Favorites uses a sidebar plus responsive grid layout.
- Channel/playlist cards have View Detail and an action menu.
- Editing, details, adding resources, categories and Learning Groups use proper extension dialogs rather than prompt-based editing.
- Learning Groups replace the ambiguous new-library "Collections" label.
- Categories have their own tab.
- Search provides suggestions from existing channels, playlists, categories and tags.

## Favorites
- Metadata and thumbnails are fetched when a channel/playlist is added.
- Category is automatically suggested from available YouTube metadata and remains editable.
- Duplicate detection uses stable Channel ID / Playlist ID and reports a 100% duplicate when the same resource already exists.
- Same display names are allowed when IDs are different.
- Learning Groups support view/edit/remove and member removal.
- Thumbnail refresh preserves notes, tags, categories and pin state.

## Transcript / AI fixes
- Dual Transcript first requests caption data through the current YouTube page bridge, reducing dependence on the player endpoint that was producing HTTP 403.
- Service-worker fallback now attempts the YouTube watch page before the InnerTube player-client cascade.
- Local AI can be enabled/tested directly from the Additional Learning window; when enabled, the first detected Ollama model can be selected automatically.
- Ollama remains optional and does not become a dependency for the existing transcript/translation engine.

## Settings
- Existing settings IDs from the supplied working version are preserved: 196/196 matched exactly against `original-working-version`.
- Existing categorized settings navigation remains page/tab based rather than one long scrolling settings page.
- New dedicated settings categories are added for Additional Services, YouTube Library and Additional Windows.
- Existing unknown stored preference keys continue to be preserved when settings are saved.

## CSP
- Favorites HTML and generated favorites UI contain no inline HTML event handlers. Event wiring uses JavaScript `addEventListener` calls to remain compatible with Manifest V3 CSP.

## Validation
- JavaScript syntax validation passes for all source JavaScript files.
- `manifest.json` validates as JSON.
- Both final ZIP archives pass `unzip -t` integrity validation.
- The `original-working-version/` directory remains byte-for-byte identical to the supplied original extension archive.
