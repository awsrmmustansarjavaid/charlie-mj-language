# Roadmap

## Current release

The current repository focuses on the requested YouTube-first workflow and provides a working local Chrome extension architecture for:

- subtitle learning
- translation
- vocabulary
- transcript export
- screenshots
- bookmarks
- Watch Later
- Focus Mode
- library dashboard

## Next major upgrades

1. Replace heuristic POS/CEFR detection with downloadable language datasets.
2. Add robust Turkish morphological analysis.
3. Add AnkiConnect and Anki package export.
4. Add SRS scheduling.
5. Add audio sentence capture and TTS.
6. Add shadowing and speech recognition.
7. Add VTT/Markdown/EPUB exports.
8. Add local translation models.
9. Add platform adapters for Netflix/Prime/BiliBili.
10. Add importers for compatible vocabulary formats from other learning tools.
11. Add AI tutor provider adapters.
12. Build a Tauri desktop edition for true filesystem control and local media.
