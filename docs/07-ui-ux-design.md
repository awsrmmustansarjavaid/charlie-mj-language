# UI/UX Design

## Visual direction

Charlie MJ Language uses a calm cinematic productivity style:

- Midnight navy background.
- Subtle indigo/purple glow.
- Glass-like cards.
- High-contrast readable text.
- Small rounded controls.
- Decoration is secondary to learning content.

## YouTube toolbar

Primary actions should remain visible:

- Focus
- Save
- Capture
- Bookmark
- Transcript
- Watch Later
- More

Less frequently used features belong behind the three-dot menu.

## Popup

The popup acts as a command center with counts for vocabulary, bookmarks and Watch Later, plus quick navigation.

## Accessibility

Future releases should support keyboard navigation, reduced motion, high contrast, large text, dyslexia-friendly fonts and non-color alternatives for grammar categories.

## RTL

The layout should support right-to-left languages such as Arabic, Persian and Urdu.
