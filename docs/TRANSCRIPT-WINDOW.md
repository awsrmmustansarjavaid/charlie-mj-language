# Transcript Window

## Existing controls
- Drag
- Resize width/height
- Minimize
- Maximize
- Pin
- Close
- Restore
- Saved position and size
- Transcript tabs
- Playback synchronization

## Dual Transcript
Dual Transcript is an additional tab and does not replace existing transcript tabs.

## Minimized restore
When minimized, move the mouse near the minimized window. An additional restore/maximize control appears so the window can be recovered without changing the existing window-management system.
