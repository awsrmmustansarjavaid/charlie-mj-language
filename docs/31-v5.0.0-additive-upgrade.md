# Charlie MJ Language v5.0.0 — Additive Upgrade

This release adds the requested systems without replacing the existing extension.

## Preservation contract

- The current working project is preserved in `original-working-version/`.
- The existing `legacy-youtube` transcript engine remains the default and is not rewritten.
- Existing storage keys and settings are preserved.
- New services use `cmj*`-namespaced storage keys.
- Every new service is optional and failures are isolated.

## Added systems

### Modular transcript services

- Native target-language track discovery.
- Auto-generated track discovery.
- YouTube auto-translation track support.
- Independent transcript alignment.
- Sentence/phrase alignment with confidence.
- Best-effort word alignment.
- Dual transcript comparison UI opened from the `Charlie MJ+` button on YouTube.

The original transcript system remains authoritative for the existing extension UI.

### Local AI — Ollama

The new Local AI panel communicates with a locally installed Ollama server. No model is bundled.

Supported tasks:

- Translation
- Vocabulary analysis
- Sentence/grammar explanation
- Translation verification
- Flashcards
- Vocabulary quizzes
- Sentence simplification
- Local activity history
- Save a word into the existing Vocabulary library

Default endpoint: `http://127.0.0.1:11434`.

### YouTube Favorites

A new independent `⭐ YouTube Favorites` workspace contains:

- Favorite Channels
- Favorite Playlists
- Learning Collections
- Notes
- Tags
- Categories
- Pin-compatible records
- Search/filter
- Direct YouTube opening
- Metadata refresh
- Thumbnail refresh metadata
- Duplicate-safe saves
- JSON backup/import
- TXT export
- Collection membership

Data is stored through `chrome.storage.local`; JSON is the portable backup format rather than a directly writable local file.

## Settings

`Settings → Additional Services` controls the new services independently:

- Dual Transcript Service
- Native tracks
- Auto-generated tracks
- Auto-translation
- Track discovery
- Sentence/word alignment
- Favorite Channels/Playlists
- Thumbnail and metadata refresh intervals
- Ollama endpoint, model, timeout, token limit and temperature
- Local AI history

## Safety

A new service failing must not disable the original transcript, translation, vocabulary, subtitle or library functionality.

## Installation

Load the `Charlie-MJ-Language` directory as an unpacked Chrome Manifest V3 extension, or package it for distribution from the supplied ZIP.
