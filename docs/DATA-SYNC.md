# Data Sync

The Data Sync workspace manages local data and optional GitHub-backed synchronization.

## Default repository
`https://github.com/awsrmmustansarjavaid/charlie-mj-language`

The URL is editable.

## Typical workflow
1. Configure the repository URL.
2. Validate local data.
3. Run Health Check.
4. Compare Local ↔ GitHub.
5. Review differences.
6. Pull/synchronize as appropriate.
7. Prepare a ZIP backup when needed.

Chrome extensions cannot silently write arbitrary filesystem paths without appropriate browser APIs or helpers.
